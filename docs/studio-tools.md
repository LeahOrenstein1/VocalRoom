# Studio tools — v0.4

The header's sun/moon button switches and remembers Dark/Light mode locally. Both use the same real cursor-responsive 3D microphone with different material colors. The pink audio-lines favicon mirrors the brand.

The first backing import names an untouched, untitled project from its filename, removing karaoke/instrumental tags. It is local filename cleanup, not an AI service. Manual names and reopened projects remain yours.

Place the playhead inside a track and choose **Split at playhead**. Both parts reference the original AudioBuffer; change their Trim in/Out values or remove a part. Trimming the start advances its timeline offset by the same amount, so retained audio stays in place. Source PCM is not rewritten. Changes invalidate the processed cache and return listening to Original; process again for an updated mix. Split parts currently serialize separate PCM copies when saving, so extensive splitting increases saved project size.

**Export audio** offers the selected Original/Processed full mix or a **dry vocal stem**. The stem includes audible vocal parts at their timeline positions, with trims, gain and pan, honoring Mute/Solo; it excludes backing and all DSP. If a backing track is soloed, un-solo it before exporting vocals. A processed vocal-only stem is not currently offered. WAV is 16-bit PCM for editing; MP3 is 192 kbps, encoded locally in an independent worker. MP3 has codec padding/delay: use WAV for sample-accurate exchange. The separate unmodified LGPL MP3 module, full license texts, attribution and corresponding-source links ship under `/licenses/` and `/vendor/`.

**Measure recording delay** opens instructions before emitting three soft chirps. Hold a wired headphone earcup by the selected microphone. This measures acoustic output+input round trip without microphone monitoring, rejects absent/inconsistent tones, and sets the correction for future takes only. Capture/playback share the AudioContext sample clock. Synthetic tests establish detector correctness, not your hardware latency. Manual correction/10 ms per-take nudges remain available. Remeasure after device changes; Bluetooth buffering can vary, and this calibration does not correct tempo drift or existing performances. The reported timing problem cannot be declared resolved until the owner records and compares a new take with their devices.

Verification: `npm test`, `npm run build`, `/tests/tools.html` (real MP3 encode/decode, dry stem isolation, split render equivalence and synthetic delay detection), plus existing audio/Studio Polish/capture browser suites. No real microphone is used by these tests. The independent Smule experiment lives under `experiments/smule-renaissance/` and is not called by any production app module.
